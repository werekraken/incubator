# contrib/smem

[[PATCH] Support KReclaimable for accurate kernel "Cache" accounting](0001-Support-KReclaimable-for-accurate-kernel-Cache-accou.patch) fixes smem's kernel cache accounting on modern Linux kernels (see embedded commit message for details).

As of November 2026, the official smem mailing list and maintainer emails at selenic.com bounce, and the tool appears to be abandonware.

This patch is provided here for package maintainers who wish to apply downstream fixes to their smem packages.
